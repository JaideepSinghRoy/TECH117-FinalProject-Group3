Introduction

The Procrastination Preventer is an automated physical lockdown safe designed to eliminate digital distractions during study and work sessions. By physically locking a smartphone inside an enclosure for a user-specified duration, the system prevents device interaction until the timer expires. The system integrates an Arduino Uno, a 5V 1602A LCD display, a keypad module, a 10K potentiometer, a motorized stepper lock, Red/Green/Blue status LEDs, and a cable access port.

What Does The Project Need To Do

  • Automated Motorized Locking & Unlocking: A 5V stepper motor automatically drives the door mechanism shut when a countdown starts and retracts the lock upon timer completion.
  • Keypad-Driven Dual Timers: The user inputs custom durations for both a Study Timer and a Break Timer using the keypad matrix.
  • Visual Telemetry & Status LEDs: A 1602A LCD screen displays live remaining time, while dedicated LEDs (Red, Green, Blue) visually signal system states (e.g., Red = Locked/Study, Green = Unlocked/Break, Blue = Menu Setup).
  • Charging & Headphone Cable Passthrough: A cut-out port allows charging or wired audio access while keeping the phone secured inside.

How We Know If It Works Well

  • Autonomous Door Operation: The box reliably closes and opens on its own at the start and end of designated timer cycles.
  • Physical Security: The locking bolt holds firmly in place during active countdowns to prevent phone retrieval before the timer reaches zero.
  • Clear Lock Confirmation: The status LED indicators provide immediate, long-range visual confirmation that the box is locked and unopenable.
  • Functional Accessibility: The charging slot allows cable connectivity without compromising the physical lock integrity.

What Might Make It Harder To Finish

  • Multi-Component Software Integration: Simultaneously controlling stepper motor steps, parsing keypad button presses, updating the 1602A LCD, and toggling RGB LEDs can lead to software delays or unresponsive inputs. Contingency: Implement non-blocking state loops using millis() timing routines instead of blocking delay() calls.
  • Keypad Input Parsing & Debouncing: Rapid or multi-key presses on the keypad matrix can corrupt input variables. Contingency: Utilize the standard Keypad.h library with built-in software debouncing routines.
  • Stepper Motor Torque & Driver Supply: The stepper motor requires precise step sequencing and stable power draw to open and close smoothly. Contingency: Power the stepper motor driver via an external 5V power supply with shared common grounding.

The potentiometer sets the timer duration, which is displayed live on the 16x2 LCD screen. Pressing the start button triggers the SG90 servo motor to rotate 90 degrees and engage the physical box latch. The Arduino counts down the remaining time on the LCD screen, holding the servo locked until the timer reaches zero.

Arduino Code (THIS SECTION IS TO BE EDITED)

The following C++ program reads time selection from the potentiometer, displays the live countdown on the I2C LCD, and actuates the servo motor latch mechanism upon button press.


#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <Servo.h>

// Hardware Pins
const int potPin = A0;
const int buttonPin = 2;
const int servoPin = 9;

// Objects
LiquidCrystal_I2C lcd(0x27, 16, 2);
Servo lockServo;

// Constants & State Parameters
const int LOCKED_POS = 90;   // Servo locked angle (degrees)
const int UNLOCKED_POS = 0;  // Servo unlocked angle (degrees)
bool isLocked = false;
int minutesToLock = 1;

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  lockServo.attach(servoPin);
  lockServo.write(UNLOCKED_POS);

  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Set Time (Mins):");
}

void loop() {
  if (!isLocked) {
    // Read potentiometer value (maps 0-1023 analog input to 1-60 minutes)
    int potVal = analogRead(potPin);
    minutesToLock = map(potVal, 0, 1023, 1, 60);

    lcd.setCursor(0, 1);
    lcd.print("Timer: ");
    if (minutesToLock < 10) lcd.print("0");
    lcd.print(minutesToLock);
    lcd.print(" mins   ");

    // Check start button press (Active LOW using internal pull-up)
    if (digitalRead(buttonPin) == LOW) {
      delay(50); // Debounce delay
      if (digitalRead(buttonPin) == LOW) {
        startLockdown(minutesToLock);
      }
    }
  }
  delay(100);
}

void startLockdown(int totalMinutes) {
  isLocked = true;
  lockServo.write(LOCKED_POS);

  long totalSeconds = (long)totalMinutes * 60;

  while (totalSeconds > 0) {
    long minsLeft = totalSeconds / 60;
    long secsLeft = totalSeconds % 60;

    lcd.setCursor(0, 0);
    lcd.print("   LOCKED OUT!  ");
    lcd.setCursor(0, 1);
    lcd.print("Time: ");
    if (minsLeft < 10) lcd.print("0");
    lcd.print(minsLeft);
    lcd.print(":");
    if (secsLeft < 10) lcd.print("0");
    lcd.print(secsLeft);
    lcd.print("   ");

    delay(1000);
    totalSeconds--;
  }

  // Timer finished - release lock mechanism
  lockServo.write(UNLOCKED_POS);
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print(" Time's Up! ");
  lcd.setCursor(0, 1);
  lcd.print(" Box Unlocked ");
  delay(5000);

  isLocked = false;
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Set Time (Mins):");
}
